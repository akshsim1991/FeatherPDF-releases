# Feather PDF

A fast, free PDF reader and editor for Windows and macOS. Everything happens on your own computer: no account, no
cloud service, no tracking. Free to use and share, always.

**Version 2.19.2**

- Windows 7 SP1, 8.1, 10 and 11 (64-bit): [FeatherPDF-Setup-2.19.2.exe](https://raw.githubusercontent.com/akshsim1991/FeatherPDF-releases/main/FeatherPDF-Setup-2.19.2.exe)
- macOS 11 or later (Apple silicon and Intel): [FeatherPDF-2.19.2-mac.dmg](https://raw.githubusercontent.com/akshsim1991/FeatherPDF-releases/main/FeatherPDF-2.19.2-mac.dmg)

Installed copies find new versions themselves (Help > Update to new version) and ask whether to update now or later.
