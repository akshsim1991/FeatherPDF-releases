# Feather PDF

A fast, free PDF reader and editor for Windows and macOS. Everything happens on your own computer: no account, no
cloud service, no tracking. Free to use and share, always.

**Version 2.19.1**

- Windows 10 and 11: [FeatherPDF-Setup-2.19.1.exe](https://raw.githubusercontent.com/akshsim1991/FeatherPDF-releases/main/FeatherPDF-Setup-2.19.1.exe)
- macOS 11 or later (Apple silicon and Intel): [FeatherPDF-2.19.1-mac.dmg](https://raw.githubusercontent.com/akshsim1991/FeatherPDF-releases/main/FeatherPDF-2.19.1-mac.dmg)

Installed copies find new versions themselves (Help > Update to new version) and ask whether to update now or later.
